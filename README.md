# PixelToolkit

Actually got the motivation to work on this again. Also need to have something
like this on my portfolio. This should be a 1:1 impl of
[PixelGraph](https://github.com/Null-MC/PixelGraph). I don't know .NET nor C#,
so rust it is. Also PG's 3D renderer doesn't work on non-Windows systems. I have
a few things planned in mind, other than the existing features; Git support,
plugins w/ Lua scripting, proper animations and CTM preview...
